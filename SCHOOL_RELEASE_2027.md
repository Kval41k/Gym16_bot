Профильная математика — 20 заданий. №6 — случайные величины, математическое ожидание, дисперсия; №13 — текстовые задачи, включая личные/семейные финансы; №17 — моделирование реальных ситуаций, в том числе оптимизация. Номер 12 не удалён: он относится к функциям и графикам. Отдельная прежняя первая часть на исследование экстремума не сохраняет старый номер. Во второй части: №14 уравнения, №15 стереометрия, №16 неравенства, №17 моделирование, №18 планиметрия, №19 параметры, №20 числа и их свойства. Ошибочная тема о комплексных числах убрана из актуального каталога.

В русском языке №22 — выразительные средства, №23 — содержание текста, №24 — типы речи, №25 — лексический анализ, №26 — связи предложений; №27 — сочинение. Прежняя нумерация тем приложения исправлена.

Добавлены **47 авторских учебных конспектов** с правилами, алгоритмом, разобранным примером, типичной ошибкой и официальной ссылкой. Это самостоятельные учебные пояснения, не скопированные тексты КИМ. Раздел называется «Профильная математика». Приложение указывает статус проекта ФИПИ-2027, а не выдаёт проект за окончательный утверждённый формат.

Имеющиеся пользовательские материалы не удаляются. При первом обновлении номера прежних тем переносятся однократно; ID, закладки и отметки изучения сохраняются. Старый материал математического №20 сохраняется в архиве прежнего формата, доступном проверенному редактору/администратору через `/api/admin/ege/archive`. Автоматическая повторная инициализация не перезаписывает последующие правки администратора.

## Мини-тренажёр

Стартовый банк содержит **150 оригинальных учебных задач**: не менее трёх на каждую тему; в математических №6, №13 и №17 — по шесть. Условия и объяснения — авторские. Это банк для тренировки навыков, а не подборка настоящих экзаменационных вариантов и не обещание исчерпывающей подготовки.

- Кнопка тренажёра находится в карточке теории.
- Числа проверяются точно, поддерживаются десятичная запятая/точка и обычные дроби. Текст нормализуется по регистру; Е/Ё при сравнении не различаются. Пользовательский ввод не выполняется как код.
- После неправильного ответа показываются правильный результат и объяснение. Ошибка остаётся в личной очереди, доступной через «Только ошибки». Обычная очередь сначала предлагает новые задачи, затем готовые к повторению; ошибку можно повторить сразу отдельной кнопкой.
- После правильного ответа конкретная задача больше не выдаётся. Решённые задачи не сбрасываются при закрытии приложения; прогресс привязан к Telegram ID и текущей БД.
- Серверная попытка принадлежит одному пользователю. Повторные и одновременные отправки одной попытки учитываются один раз. Ответ и объяснение не выдаются до отправки решения. Попытка действует 30 минут.
- Для сочинения и математических №14–20 проверяются отдельные объективные навыки и вычислительные шаги. Полный текст сочинения/доказательства автоматически по критериям ЕГЭ не оценивается; это явно написано в интерфейсе.
- Изменения числового прогресса доступны в административном журнале; текст ответов не копируется туда. Резервная копия включает личные очереди и попытки.

Хранение остаётся в текущей БД проекта. Переезд на постоянную БД/хостинг 24/7 по решению владельца отложен; эта версия не устраняет ограничения временного файлового хранилища Render.

## Расписания

Источники — пять фотографий владельца и его письменные уточнения. Снимки не публикуются в репозитории; структурированные строки и замечания к чтению находятся в `data/photo_timetables_20261025.json`.

- **11Д:** самостоятельное расписание вместо прежнего клона 11В. Различены обе подгруппы, в том числе пустой первый урок у одной из групп в среду/четверг.
- **11Г:** пары, учителя и кабинеты перенесены по таблице. Рукописные «ХИМ», «МАТЕМ», «РУСС» записаны как консультации среды/четверга/пятницы в 14:40–15:20. Учителя по подтверждению владельца: Юрина Т.Ю., Захарова Н.А., Шабалина Е.В. Кабинеты не выдумываются.
- **11Ж:** учтены пары физкультуры и физики, а также асимметричные подгруппы: у второй группы нет седьмого урока среды, у первой нет седьмого урока пятницы.
- **11В:** профиль «Инфотех» соответствует «у нас», профиль «Инженерный» — «физикам/инженерам». Владелец отдельно подтвердил первые два урока пятницы: 1) Инфотех — английский, Инженерный — физика; 2) Инфотех — физика, Инженерный — английский. Во вторник выставлены пары информатики/физики, русского, геометрии; в четверг седьмым — зачёт по математике. Остальные читаемые позиции сохранены по фотографии. Заголовок исходного снимка — 10В, но файл дан владельцем именно для 11В. Консультация другой группы 10З не перенесена.
- В информатике вторника 11В на фото указаны два учителя/кабинета без подписанных подгрупп: эти данные сохранены вместе с отметкой, что распределение уточняется. Для консультации по информатике понедельника время на фото не указано; приложение его не придумывает.
- **11А, филологический:** время унифицировано с соц-гум. Старое смещение нумерации понедельника 1–8 исправлено на 0–7. Предметы филологического профиля сохранены. Старые подписи, содержащие только прежнее время урока, убраны; содержательные примечания сохранены. Общая субботняя консультация остаётся общей.
- **11Б:** добавлено расписание по новой фотографии: 39 записей с учётом подгрупп, 35 различных уроков; число уроков по дням — 8/7/7/6/7. В пятницу группы меняются информатикой и английским на уроках 5 и 6. Четверг заканчивается после шестого урока; суббота пуста. Источник — отдельный `data/11b_reviewed_20261025.json` с самостоятельной ревизией.

Перед изменением сохраняется локальная копия прежних строк. Обновление помечается ревизией и не повторяет замену при перезапуске. Ручные исключения на конкретные даты остаются самостоятельными административными правками.

В ученическом расписании удалено поле выбора даты и произвольный переход по неделям. Остаются дни недели, день/неделя, «Сегодня» справа. Администратор по-прежнему может создавать замены на дату. Для классов с подгруппами появились явные переключатели «Обе группы / 1 / 2». В профиле можно выбрать личную подгруппу для карточки и напоминаний.

## Внешний вид и проверка

Вместо стандартного выпадающего списка времени напоминания — ползунок 5/10/15 минут с крупным значением и кнопками точного выбора. Сохранены управление клавиатурой, подпись для экранного диктора и сохранение через существующие настройки.

Проверки:

```sh
python tests/check_features.py
python tests/check_calendar_sync.py
python tests/check_security_and_comments.py
python tests/check_community.py
python tests/check_school_release.py
python tests/check_11b_transcription.py
node tests/check_theme.cjs
pnpm run build:css
```

Новый набор независимо проверяет важные строки с фотографий и пустые ячейки подгрупп, подтверждённые перестановки 11В, часы обоих профилей 11А, заполнение всех тем, перенос прежних материалов/закладок, недоступность ответов до решения, изоляцию попыток, одновременные повторные отправки, очередь ошибок, исключение освоенных задач, все числовые ключи математики и восстановление резервной копии с новыми таблицами. В браузере проверены теория, цикл «ошибка → повторение → правильный ответ», новый ползунок, отсутствие поля даты и переключение подгрупп.

Отчёты: [сверка учителей и расписаний](TEACHER_TIMETABLE_REVIEW.md), [проверка учебного содержания](EGE_CONTENT_REVIEW.md).

Подтверждённое владельцем написание **Буракевич Ю.Ю.** применено к 11Д и к опечатке календарного снимка 11А. Прежние установленные строки 11А исправляются адресно; похожие фамилии других учителей автоматически не объединяются. Полные имена вместо инициалов по предположению не дописываются.

В русском тренажёре убрано дублирование слов в двух условиях о НЕ, объяснение больше не ссылается на позицию варианта до перемешивания, устранена неоднозначность союза И при общей придаточной части. Допустимая словарями форма «носок» не используется как неверный ответ; в вопросе о «договоры» уточнена строгая литературная норма.
