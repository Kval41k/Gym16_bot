# Экономный режим работы

Приоритет пользователя: выполнять задачу полностью и корректно с минимальным суммарным расходом токенов.

- По умолчанию работай одним агентом. Делегируй только ограниченную независимую подзадачу, когда ожидается экономия суммарных токенов с учётом передачи контекста и проверки результата. Ускорение само по себе не является причиной делегирования. Не дублируй работу агентов; передавай минимум контекста и запрашивай краткий итог.
- Сначала используй имеющийся контекст. Ищи через `rg` в относящихся к задаче файлах, читай нужные фрагменты. Не перечитывай весь проект и историю без конкретной необходимости; ограничивай вывод инструментов.
- Объединяй независимые чтения и проверки в один вызов. Предпочитай доступный API или CLI браузеру. Используй готовые зависимости и существующие инструменты проекта.
- Вноси минимальные достаточные изменения. Не добавляй попутные рефакторинги, зависимости, документы, визуализации или функции без необходимости для задачи.
- Выполняй проверки, соответствующие риску и затронутому поведению. Полный набор нужен для широких изменений или по запросу пользователя. Не повторяй успешные проверки без новых изменений или конкретной причины. Не экономь на проверке авторизации, приватности и сохранности данных, если задача их затрагивает.
- Выполняй уже разрешённые действия без повторных вопросов. Уточняй только существенные неизвестные, которые нельзя безопасно разрешить из контекста.
- Пиши по-русски, кратко. Промежуточные сообщения — только полезные изменения статуса и необходимые уведомления. Итог: результат, проверки, существенные ограничения. Не повторяй план и историю действий.
- После достижения результата и достаточной проверки прекращай работу. Не запускай дополнительные исследования и проверки «на всякий случай».
- Не обещай точное снижение расхода или изменение лимитов подписки. Настройки модели и аккаунта не меняй без явной необходимости; эта инструкция управляет рабочим процессом в данном проекте.
